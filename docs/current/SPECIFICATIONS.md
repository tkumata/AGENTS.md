# Codex 専用インストーラ仕様

状態: 提案（実装未承認）

## 目的と範囲

`install.sh` を Codex 専用にし、グローバル指示とスキルのシンボリックリンク作成、エージェント定義のコピー、および既存ハーネスのプロジェクトへの導入を行う。

実装対象は `install.sh`、`merge.py` の不要な他エージェント専用処理、関連テスト、`README.md` の導入説明とする。既存の未コミット変更は保持する。

## 確定事項

### グローバル指示とスキル

| リンク元 | 作成先 |
| --- | --- |
| リポジトリ直下の `AGENTS.md` | `~/.codex/AGENTS.md` |
| `codex-skills/xxx` の各スキルディレクトリ | `~/.codex/skills/xxx` |

- ファイルのコピーではなくシンボリックリンクを作成する。
- `~/.codex/AGENTS.md` に既存ファイルまたはリンクがあれば、置換・削除・マージしない。
- `~/.codex/skills/xxx` に既存ディレクトリまたはリンクがあれば、置換・削除・マージしない。
- リンク切れや、同じリンク元を指す既存リンクも既存リンクとして扱う。

### エージェント定義

- `codex-agents/` 直下の各ファイル `xxx` を `~/.codex/agents/xxx` にコピーする。シンボリックリンクは作成しない。
- コピー先に同名ファイルがあれば、内容が同一かどうかにかかわらずスキップし、置換・削除・マージしない。

### 既存パスのスキップ

- グローバル指示、スキル、エージェント定義の配置先に既存パスがある場合は、その項目だけをスキップする。
- 残りのリンク作成、エージェント定義のコピー、ハーネス導入は継続する。スキップだけでは失敗終了しない。

### Codex 専用化

- エージェント選択を削除し、Codex を固定の対象とする。
- インストーラとマージ処理の Claude Code／Copilot 専用コード、およびそれらを導入するためのテストを削除する。
- プロジェクトに既存の Claude Code／Copilot 設定があっても削除・更新しない。

### ハーネス

- プロジェクトのパス入力と `rust`、`pico-sdk`、`esp-idf` の環境選択を維持する。
- 選択環境の共通ファイルと Codex 設定を配置する。Claude Code／Copilot 設定は配置しない。
- 新規コピー、同一内容の保持、対応形式の不足項目マージ、競合時の配置前エラー、ファイル権限の保持という既存動作を維持する。
- `harness/` 以下の既存ロジックは変更しない。他エージェント対応の削除範囲をハーネス内部へ広げない。
- `--help`、`--dry-run`、不正な引数の拒否を維持する。
- `--dry-run` はグローバルリンクの作成予定、エージェント定義のコピー予定、各項目のスキップも表示し、ホームと対象プロジェクトを変更しない。

## 仮定と境界条件

- 指示ファイルの位置にディレクトリ、スキルの位置に通常ファイル、エージェント定義の位置にディレクトリやリンクなど、想定外の種類の既存パスがある場合も上書きせずスキップする。リンク切れも含む。
- `~` は実行時の `HOME` とする。配置先を変更する新しいオプションは追加しない。
- 必要な親ディレクトリは通常実行時に作成し、リンク元はインストーラの所在を基準にした絶対パスとする。
- `codex-skills/` 直下のスキルディレクトリを対象とし、内部のファイルを個別にリンクしない。
- ディレクトリ作成、リンク作成、ファイルコピーの実際の失敗は、既存パスのスキップと区別し、理由を表示して非ゼロ終了する。
- 入力とハーネスの競合検査はリンク作成とエージェント定義のコピーを含む配置開始前に完了する。配置開始後の I/O 失敗に対するロールバック機構は追加しない。

## 受け入れ条件と検証

- 空の一時 `HOME` で、指示ファイルと各スキルが正しいリンク元を指す。
- 各エージェント定義が `~/.codex/agents/` に同名・同内容の通常ファイルとしてコピーされる。
- コピー先に同名ファイルがある場合は内容と更新日時を保持し、未配置のエージェント定義のコピーを継続する。
- 既存ファイル、ディレクトリ、同一・別宛先・リンク切れのリンクを保持し、他の項目の処理を継続する。
- 再実行でリンクやコピー済みのエージェント定義を置換せず、同一ハーネスのファイルを更新しない。
- `--dry-run` でホームとプロジェクトの内容を変更せず、リンク作成・エージェント定義のコピー・スキップと既存のハーネス変更予定を確認できる。
- 3 環境ともエージェント選択なしで Codex 用ハーネスを導入できる。
- 既存のマージ、競合時の事前停止、権限保持、不正引数のテストを維持する。
- `tests/install_test.sh` は一時 `HOME` を使い、実際の `~/.codex` を変更しない。関連するマージテストも対象とする。
- 実装後に Bash 構文検査、対象テスト、差分検査を行う。本仕様の作成時点では実装検証は未実施。

## 現状との差異

現在の `install.sh` はグローバル指示・スキルのリンクを作成せず、3 エージェントの選択を受け付ける。`merge.py` にも他エージェント向け分岐が存在する。

また、現在のテストは `docs/AGENTS.md` 等のリンク作成を期待しているが、インストーラには対応するリンク作成処理がない。今回の仕様はグローバルの `AGENTS.md` を配置するものであり、旧ドキュメントリンク機能の復元は含めない。関連する残存処理とテストの期待値は今回の配置仕様に合わせて整理する。
