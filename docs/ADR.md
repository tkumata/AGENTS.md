# ADR: Explicit Template Override Mode

## Status

Accepted

## Context

形式別マージは既存設定を保護できるが、同名の Makefile ターゲットや任意のシェル
スクリプトに差異がある場合は、安全に統合できず停止する。利用者がテンプレート版への
全面置換を意図している場合にも、各ファイルを事前に手作業で削除する必要がある。

## Decision

`install.sh --override` を追加する。明示された場合、テンプレートに含まれる異なる内容の
既存通常ファイルを、テンプレートの内容とファイルモードで全面置換する。

テンプレートに存在しない配置先ファイルは変更しない。シンボリックリンク、特殊ファイル、
ファイルとディレクトリの型衝突は上書きせず、通常モードと同様にPreflightで停止する。
通常モードの意味的マージと競合検出は変更しない。

## Rationale

- オプション指定そのものを全面置換への明示的な同意として扱える。
- 任意テキストを不完全に合成せず、テンプレートが検証済みの単位を保てる。
- 通常モードを安全な既定値として維持できる。
- テンプレート外のプロジェクト固有ファイルを削除しないため、影響範囲が明確になる。

## Consequences

- `--override` では対象ファイル内のプロジェクト固有設定が失われる。
- 上書き対象の実行権限を含むモードはテンプレート側へ揃う。
- 型衝突やシンボリックリンクは、オプション指定後も手動調整が必要になる。

## Rejected Alternatives

### Override Conflicting Definitions Only

シェルスクリプトなど意味単位を安全に抽出できないファイルへ適用できず、オプションの挙動が
形式ごとに変わるため採用しない。

### Delete the Destination Tree First

テンプレート外のプロジェクトファイルまで失うため採用しない。

### Interactive Per-file Confirmation

自動実行を妨げ、利用者への質問を2項目に限定する既存要件にも反するため採用しない。
